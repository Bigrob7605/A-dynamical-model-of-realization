Formalized mechanisms
Why formalization matters: The model is not just poetic—it has actual structure. Below are the operational definitions of three frequently questioned mechanisms.

① Compute Cost / Resistance

Definition: R(t) = WM_saturation(t) + λ·ΔE_metabolic + β·ΔP_stability

Components:
• WM_saturation: Working memory load. New model must fit within ~3–4 slots of active attention. Saturated WM → cost spike to 1.0; clean fit → near 0.
• ΔE_metabolic: Free-energy change. Old model requires E₀ cal/min; new model costs E₁. If E₁ > E₀, resistance increases proportionally (λ ≈ 0.003 cal⁻¹).
• ΔP_stability: Prediction stability penalty. Each model switch disrupts ongoing predictions. High-stakes contexts (driving, social interaction) → β ≈ 0.8; low-stakes → β ≈ 0.1.

Operationally: If R(t) > 0.65, the insight is classified as noise and discarded, no matter how valid it is. This is why you don't have a mystical experience every time you find your car keys.

② Viability Filter

Definition: A new model is viable if it maximizes (Compression, Accuracy, Actionability) subject to constraint resolution.

Criteria:
• C (Compression): Kolmogorov complexity. New model must explain more with less code/structure. ΔC > +0.15 bits/element required.
• A (Accuracy): Prediction error on held-out reality. Must reduce MAE by ≥10% on external validation data.
• G (Actionability): Does it guide novel behavior that produces real-world rewards? Binary: yes or no.

Conflict resolution (when C↑ but A↓):
Primary rule: Accuracy is the constraint. If the new model improves compression but worsens predictions, revert to the reject path (stage 07).
Tiebreaker rule: When A is identical, Actionability breaks ties. A model that compresses elegantly but produces no new behavior reverts to reject.

Result: Genuine insight ≠ intellectually satisfying delusion. This is what separates paradigm collapse from pathology.

③ Field-like Topology (Mathematical Definition)

Definition: Field-like structure is characterized by the loss of modularity (Q) and emergence of global synchrony.

Metrics:
• Q (Modularity score): Measure of distinct clustering. Q ∈ [0,1]. Sparse/Clustered: Q ≈ 0.4–0.6. Integrated: Q ≈ 0.1–0.3. Field-like: Q ≈ 0 (loss of clusters).
• Global Sync (C_clustering coefficient): Probability that neighbors of a node are also neighbors. Low C → linear chains. High C → dense local clusters. Field-like has high C at all scales (near 1.0).
• L (Mean path length): Average steps between nodes. Sparse nets: L ≈ log(N). Field-like: L → 1 (every node reachable in one hop).

Phase transition markers: When Q drops below ~0.15 AND C exceeds ~0.85 simultaneously, the network undergoes topological phase transition. Subjective experience: "self and world boundaries collapse" — geometrically, they do.

Outcome spectrum — six levels + mechanics
Outcome 00
Discarded
Prediction error exists but restructuring cost exceeds benefit. Model patches locally or ignores the signal entirely. Classified as noise via compute cost threshold (R > 0.65).
Outcome 01
Local / everyday insight
Small model update. Low disruption, low cost. Associations shift in a narrow domain and are quickly integrated back into the baseline. Topology: sparse to clustered.
Outcome 02
Profound insight
Multiple domains reorganize simultaneously. Strong compression (C↑ ≥ 0.15 bits/element) + maintained accuracy. Topology: integrated. Cross-domain links form and persist.
Outcome 03
Paradigm collapse
Core assumptions invalidated. Cognitive restructuring is extreme (depth > 75). You realize you are not just a player in the game — you are part of the code. Integration phase is demanding.
Outcome 04
Peak / mystical state
System-wide surge. High coherence + high emotion + reduced self-boundary (Z↑). Topology becomes field-like (Q ≈ 0, C ≈ 0.95, L ≈ 1). Qualitatively distinct from paradigm collapse — phase transition, not continuum.
Failure mode
Pathology
High intensity + low coherence + low constraint. Destabilization persists without successful restructuring. Reality feedback fails to correct emerging beliefs. System remains fragmented.

System modulators — four dynamic variables
Amplifier
Emotional / physiological intensity
Amplifies the entire process. Low emotion + strong cognition = "interesting." The same cognition with high emotion = "this changes everything." Operationally: gain control on salience reweighting and peak integration surge amplitude.
Z-axis / Phase space
Self-boundary stability (Z)
The degree to which the self is experienced as distinct from environment. Rigid = ordinary cognition. Progressively dissolved = profound insight → mystical → pathological. The critical variable separating peak states from ordinary profound insight. Topologically: triggers Q→0 and C→1 phase transition.
Gatekeeper
Compute cost / resistance
R(t) = WM_sat + λ·ΔE_metabolic + β·ΔP_stability
Working memory saturation (new model must fit ~3–4 slots) + metabolic efficiency penalty + stakes-based prediction disruption cost. Threshold: R > 0.65 → signal discarded as noise.
Error correction
Constraint — reality feedback
Operationally: A (Accuracy) is the constraint. New model must reduce prediction error ≥ 10% on external validation. When compression (C) improves but accuracy (A) drops, revert to reject path. This separates genuine insight from delusion.
